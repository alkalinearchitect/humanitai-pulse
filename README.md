# HumanitAI Pulse

A public nervous system for UK communities. HumanitAI Pulse observes social pressure,
connects people to help, exposes institutional friction, simulates preventive action, and
measures what improved — before human difficulty becomes institutional crisis.

**Free by design.** Open-source intelligence (public UK data + live RSS) and a free LLM
(`tencent/hy3:free` via Nous Portal). No per-query API bills.

See [`ARCHITECTURE.md`](./ARCHITECTURE.md) for the full system design, the OSINT layer,
and the module map.

## Principles
- Make the invisible visible, measurable, understandable, actionable.
- Never false precision — every score tagged measured / reported / estimated / predicted / simulated.
- AI recommends; people decide.
- The enemy is the weakness inside, never an external scapegoat.

## Modules
Community Pulse · Help Now · Friction Monitor · Prevention Radar · Intervention Lab · Impact Tracker.
